# Hifz Management System — Product Requirements Document

## 1. Project Overview

The Hifz Management System is a web-based application designed to help Quran students manage, track, practice, and revise their Hifz journey.

The system provides students with tools for Quran reading, listening, memorization practice, voice practice, revision, quizzes, progress tracking, achievements, daily goals, and subscription plans.

The system also includes separate dashboards for students, teachers, and parents to support different roles within the Hifz learning process.

## 2. Project Objectives

The main objectives of the system are:

* Help students organize their Hifz journey.
* Track memorized Ayahs and Juz.
* Provide Quran reading and listening tools.
* Support daily memorization goals.
* Provide revision and practice features.
* Allow students to practice recitation using their voice.
* Provide Hifz quizzes in an understandable format.
* Reward students through achievements.
* Provide teachers with student progress information.
* Provide parents with information about their child's Hifz progress.
* Provide a structured and user-friendly interface for Hifz management.

## 3. Target Users

### Student

Students can:

* View their Hifz dashboard.
* Track memorized Ayahs and Juz.
* Set and follow daily Hifz goals.
* Read the Quran.
* Listen to Quran recitation.
* Practice memorization.
* Record and practice their own recitation.
* Perform revision.
* Take Hifz quizzes.
* View achievements.
* Manage their account settings.
* View available subscription plans.

### Teacher

Teachers can use the teacher dashboard to monitor and manage student Hifz progress and provide feedback.

### Parent

Parents can use the parent dashboard to monitor their child's Hifz progress and learning activity.

## 4. Main Features

### Authentication

* User registration.
* User sign-in.
* Role-based access.
* Persistent login using local storage.
* Supabase authentication integration.

### Student Dashboard

The student dashboard provides:

* Hifz journey overview.
* Juz completion statistics.
* Ayahs memorized statistics.
* Daily streak.
* Achievement count.
* Today's Hifz progress.
* Current Surah.
* Next revision.
* Recent activity.
* Daily Hifz plan.
* Overall Hifz progress.
* Daily target.
* Quick actions.

### Quran Reader

The Quran Reader allows students to read Quranic Ayahs inside the application.

### Listen & Practice

Students can:

* Select a Surah.
* Select a reciter.
* Listen to Quran recitation.
* Start practice from the listening section.

### Voice Practice

The system provides a voice-practice feature that allows students to practice their own recitation.

### Revision

Students can review their memorized material and complete revision activities.

### Hifz Quiz

The system provides a Hifz quiz feature to help students test their Quran knowledge.

### Achievements

Students can view achievements and rewards based on their Hifz progress and completed activities.

### Daily Hifz Goals

Students can create and follow daily memorization targets.

### Subscription

The system provides subscription plans:

* Free
* Hifz Plus
* Hifz Pro

Students can select a plan and go through a demo purchase flow.

The current payment process is a demonstration and does not process real payments.

### Settings

Students can manage application settings and profile-related information.

3. Store Hifz progress data.
4. Display memorized Ayahs and Juz statistics.

6. Provide Quran audio listening functionality.
