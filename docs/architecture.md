# Hifz Management System — System Architecture

## 1. Architecture Overview

The Hifz Management System is a web-based application built using React and Vite on the frontend and Supabase for backend services and data storage.

The system follows a component-based architecture where different features are organized into separate React pages and components.

## 2. Technology Architecture

The main technologies used in the project are:

* **Frontend:** React
* **Build Tool:** Vite
* **Programming Language:** JavaScript
* **Styling:** CSS
* **Backend Services:** Supabase
* **Database:** Supabase PostgreSQL
* **Authentication:** Supabase Authentication
* **Client Storage:** Browser Local Storage
* **Audio:** Quran recitation audio services

## 3. High-Level Architecture

The application can be represented as:

```text
User
  ↓
React Frontend
  ↓
Application Pages & Components
  ↓
Supabase Client
  ↓
Supabase Service
```
